
# 📦 Circular Queue Using Array (C++)

This project demonstrates a **circular queue (FIFO - First In First Out)** data structure implemented using a **dynamically allocated array**. It provides basic queue operations, proper memory handling, and user interaction .

## 🧠 Key Concepts

- **Circular Queue**: A queue where the last position is connected back to the first to make a circle. This avoids wasting space in linear arrays.
- **Dynamic Memory Allocation**: The size of the queue is not hardcoded but is provided by the user during program execution.

## 🧰 Features

- **Enqueue()** (Add element)
- **Dequeue()** (Remove element)
- **IsFull()** Check if queue is full 
- **IsEmpty()** Check if queue is Empty 
- **Print()** Display all elements
- **(GetLength)** Get current number of elements
- **Front()** Get front element
- **End()** Get end element
